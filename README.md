# CalledB

Who is on call, by department. A phone-first calendar for hospital call lists.

- Pick your hospital and department once; the phone remembers it.
- Each department's list is encrypted. To open it you need the passcode your department shares.
- Add the page to your Home Screen and it opens full screen, and without signal once it has loaded.

Nothing in this repository can be read without a department's passcode.
